# 꽃순이 오피스 · 합동 비서실

가족과 비서들이 함께 쓰는 **실시간 합동 비서실**입니다. GitHub Pages로 바로 열리는 정적 웹앱이며,
Firebase Realtime Database를 연결하면 여러 기기에서 내용이 실시간으로 함께 바뀝니다.
연결하지 않아도 **로컬 모드**(이 기기의 `localStorage`)로 그대로 동작합니다.
홈 화면에 설치되는 **PWA(설치형 웹앱)** 로도 쓸 수 있습니다.

- 배포 주소: <https://namsoo22.github.io/HOMEPAGE1/shared-office/>

## 기능

| 화면 | 내용 |
| --- | --- |
| 🏢 오피스 | 아이소메트릭 오피스 도면(`office-scene.png`)과 6개 핫스팟 핀. 핀을 누르면 그 자리의 최근 진행 현황(접속 상태 · 최근 공지 · 미완료 할 일 · 자녀별 최근 항목 · 최근 채팅)이 바로 열리고, 해당 탭으로 이동할 수 있습니다. `모션 ON/OFF`로 핀의 둥실거림을 켜고 끕니다. |
| 📌 공유 보드 | 공지 · 요청 · 메모 글쓰기, 작성자 태그, 상단 고정, 수정 / 삭제 |
| ✅ 공동 할 일 | 제목 · 담당자 · 기한 · 우선순위, 완료 체크, 전체 / 미완료 / 완료 필터 |
| 🧒 아이들 보드 | 자녀별 탭(이름 · 이모지 편집 가능), 준비물 · 일정 · 전달사항 카드와 체크 |
| 💬 채팅 | 메신저형 말풍선 대화, 작성자 선택(정석·미경 비서 등 · 직접 입력), Enter 전송 / Shift+Enter 줄바꿈, 내 메시지만 삭제 |
| 👥 현황 | 이름별 상태 한 줄, 마지막 업데이트 시각, 접속 중 표시(1분 하트비트) |

- 입장 코드 잠금 화면이 있어 코드를 넣어야 내용이 보입니다.
- 상단 배지는 실시간 DB 연결 시 `• LIVE`, 로컬 모드일 때 `• 로컬`로 표시됩니다.
- 모바일(iPhone) · PC 반응형.

## 홈 화면에 설치 (PWA)

- **iPhone(Safari)**: 공유 → *홈 화면에 추가*
- **Android(Chrome)**: 메뉴 → *앱 설치* / *홈 화면에 추가*
- `manifest.json`(앱 이름 · 아이콘 · 테마 색)과 `sw.js`(정적 리소스 네트워크 우선 + 폴백 캐시)로 동작하며,
  Firebase·외부 API 요청은 서비스 워커가 가로채지 않고 그대로 통과시킵니다.

## 채팅 데이터

- 실시간 DB 모드에서는 `chat` 경로에 `{ author, text, createdAt }` 형태로 저장됩니다(`push` / `onValue` / `remove`).
- 로컬 모드에서는 같은 구조가 `localStorage`에 저장되어 동일하게 동작합니다.

## 파일 구성

```
index.html          화면 구조 (오피스 대시보드 + 5개 탭)
style.css           디자인 (라이트 그레이 · 둥근 카드 · 다크 네이비 포인트, 반응형)
app.js              앱 로직 · 오피스 핀/패널 · 저장소 추상화(로컬 / Firebase)
firebase-config.js  Firebase 설정 (비어 있으면 로컬 모드)
manifest.json       PWA 매니페스트
sw.js               서비스 워커 (오프라인 폴백 캐시)
office-scene.png    아이소메트릭 오피스 일러스트
icon-512.png        앱 아이콘 (512×512)
apple-touch-icon.png iOS 홈 화면 아이콘
```

## 실시간 DB 연결

1. Firebase 콘솔에서 프로젝트를 만들고 **Realtime Database**를 생성합니다.
2. 프로젝트 설정 → 일반 → 내 앱(웹) → SDK 설정의 구성 객체를 복사합니다.
3. 앱 화면 상단의 **[LIVE / 로컬]** 배지를 누르고, 설정 JSON을 붙여넣은 뒤 **연결**을 누릅니다.
   (설정은 그 브라우저에 저장됩니다.)
4. 모든 사용자에게 적용하려면 `firebase-config.js`의 `FIREBASE_CONFIG`에 같은 값을 넣고 다시 배포합니다.

`databaseURL`이 반드시 포함되어야 하며, DB 규칙(Realtime Database → 규칙)에서 읽기/쓰기를 허용해야 합니다.
비공개로 쓰려면 Firebase Authentication과 규칙을 함께 설정하세요.

## 입장 코드

- 기본 코드는 `app.js` 상단의 `DEFAULT_ENTRY_CODE`에 있습니다.
- 앱의 ⚙️ 설정 → **입장 코드 변경**에서 브라우저별로 바꿀 수 있습니다(로컬 저장).
- 잠금 화면은 내용을 가리는 용도이며, 실시간 DB에 저장된 데이터의 접근 권한을 대신하지는 않습니다.
  민감한 정보는 Firebase 보안 규칙으로 함께 보호하세요.

## 개인정보

- 공개 저장소입니다. 코드에는 어떤 개인정보도 하드코딩되어 있지 않으며, 예시 데이터는 일반적인 문구입니다.
- 실제 내용은 브라우저 로컬 저장소 또는 사용자가 연결한 Firebase DB에만 저장됩니다.
