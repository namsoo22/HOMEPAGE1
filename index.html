연결 정보

미연결
브라우저에 NAS 관리자 계정이나 비밀번호를 저장하지 마세요. 외부 접속은 HTTPS, 방화벽, 계정 권한, VPN 등 보안 설정을 먼저 검토하고 API 인증은 서버 측에서 처리하는 구성이 안전합니다.
